### Installation
- Download the script
- Drag & drop `kypz_elevator` folder into your resources directory
- Add ensure `kypz_elevator`
- Restart your server!

- ### Other Settings
- `Config.UseCutscene` To use the Live 3D Elevator Cabin Cutscene.
- `Config.UseCutscene` Transition time per floor in milliseconds.
